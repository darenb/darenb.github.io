# Retired Hugo site

This former sample blog has moved to https://www.darenbrantley.com/.

GitHub Pages publishes only `redirect-site/`. The root, previous HTML routes,
and fallback page send visitors to the current site using an HTML refresh
and a visible link. GitHub Pages does not provide an HTTP 301 for these pages.

The Hugo source and theme reference remain here for historical reference;
Hugo is no longer needed for deployment. The pre-retirement revision is
`d2545da97854c049f53548666f8b9ad370429140`.

To restore the previous site, unarchive the repository if necessary and restore
that revision's deployment workflow, then run it. Existing local worktrees
and uncommitted changes were not modified by this retirement.
